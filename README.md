# ECHO
Project ECHO is a modularly desgined LCD meter built on the NUCLEO-G431KB. In its current form it measures, resistance capacitance and inductance. Displays the result on a 20x4 I2C LCD. The meter is controled with two buttons.
## Getting setup
- First check the hardware guide in WIRING.md.
- Install the recommend VScode extentions.
- Build with Ctrl+shift+B.
- Flash the build to your NUCLEO-G431KB.
